Symmetry closure

Each assembly was regenerated by applying its deposited operators, then the operator set was checked rather than its label believed. All three close under composition with rotation-order spectrum 1×identity, 15×2-fold, 20×3-fold, 24×5-fold = 60, which is the icosahedral group I. Worst orthonormality residual across all three is 1.1×10-6 (dimensionless).

An earlier version of this check reported 12 unidentified operators because it matched only rotations by 2π/n. Five-fold axes also carry 4π/5, which is still an order-5 element. The spectrum above is after that fix.

Interface classes are recovered from geometry by grouping contact edges on their centroid separation. Each class is then deleted in full and the shell remeasured. At the percolation cutoff (4.0 nm) the baseline is β0 = 1, β1 = 271, λ2 = 0.0272.

A single 60-edge class at 3.8 nm, only 10.5% of all contacts, fragments the shell into 42 pieces and takes λ2 to zero. That is one edge per icosahedral asymmetric unit.

Two limits, both load bearing on the conclusion. First, this measures structural importance to graph connectivity. It is not mechanical load bearing, which needs an elastic-network or normal-mode analysis. Geometric integrity, graph connectivity and mechanical stability are three distinct properties. Second, which class fragments the shell is itself cutoff dependent: at a 4.6 nm cutoff no class fragments it. The honest statement is the whole curve below, not any single cutoff.

Match or rhyme

Each pair is compared on a scale-free six-component shape fingerprint, standardized across the reference set. The floor is 2 standard deviations of the distance to a size-, count- and thickness-matched random-shell null (12 seeds), using the floor_from_sham rule from your own bioenergy exercise 6.1. A pair that is not closer than that floor is a rhyme.

The one pair that clears the floor is dArc1 against Ty3, the two Gag-derived shells. dArc1 against a real T=4 ssRNA virus does not clear it, and neither does dArc1 against an idealized T=4 lattice.

This is one positive out of seven comparisons with no multiple-comparison correction. At a 2-sigma floor roughly one false positive is expected by chance, so it is a single provisional result and not a confirmed finding. A further flaw remains: all fingerprints were evaluated at dArc1's 4.0 nm cutoff although the shells differ in radius from 15.2 to 24.7 nm, so the cutoff is not scale normalized. Every verdict here is provisional on that fix. Component 2, relative shape anisotropy, is 0.0000 for every structure and carries no information.
A match candidate is a geometric statement. It never licenses :is_homologous_to or :causally_connected; those require a populated citation field and the engine refuses to create them.

Gaps

There is no high-resolution mammalian Arc capsid structure. Every icosahedral measurement on this page is Drosophila dArc1 or yeast Ty3. Mammalian Arc has only domain structures (6GSE, 4X3H). Whether mammalian Arc forms an icosahedral shell of any T number is open, and the popular account is loudest exactly where the coordinates are absent.
Deferred to Release B, by review. The cargo and electrostatics work is not in this build. Manning 1−1/ξ is an ideal-line baseline, not an ion counter; the competing diffuse-layer treatment (Vinogradova & Silkina, arXiv:2610.39661, 29 Oct 2026) argues the plateaus are often never reached for ξ ≤ 5. Release B carries Qbare, Qnear and Qeffective separately and never collapses them into one fraction.
Still to fix in Release A. Scale-normalize the contact cutoff per structure; drop the uninformative anisotropy component; widen the null ensemble; add an all-atom minimum-distance interface criterion in place of centroid separation.
